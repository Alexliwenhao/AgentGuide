# AgentGuide
# 工业级 AI Agent 开发实战：从原理到工程化落地

## 核心认知：玩具级与工业级的本质区别
* **玩具级（PoC）**：关注模型能否在理想环境下完成一次任务，Demo 演示成功即视为成功。
* **工业级系统**：需应对真实场景的复杂性，包括**异常处理、高并发支持、Token 成本控制、数据权限管理、系统自恢复能力**，以及支撑商业化落地的全栈工程化平台。

---

## 第一部分：原理与概念篇

### 1. LLM 调用的本质
* **HTTP 请求过程**：一次调用包含请求构造、传输、响应解析的全链路。
* **消息结构角色**：
    * **System**：设定行为规则与约束。
    * **Human**：用户输入的意图表达。
    * **AI**：模型生成的响应内容。
* **Token 处理**：文本通过编码转化为数字，上下文窗口限制实际计算资源。
* **温度与采样**：调整概率分布以控制输出的随机性与确定性。
* **流式输出**：基于 Server-Sent Events (SSE) 实现实时增量返回。

### 2. Prompt 设计的核心
![上下文学习资料](docs\context-engineering-practices.md)
* **结构化注入**：通过上下文构造引导模型行为，非“玄学咒语”。
* **System Prompt 优先级**：解析模型优先遵循系统指令的机制。
* **Few-shot 示例**：通过隐式格式约束规范输出，而非直接教学。
* **结构化输出**：JSON 等格式解析比纯文本解析更可靠。

### 3. Memory 管理机制
* **无状态本质**：每次请求独立，记忆通过外部存储模拟。
* **三种记忆形态**：
    * **完整历史**：全量上下文，但受 Token 限制。
    * **滑动窗口**：保留最近交互，平衡资源与效果。
    * **摘要压缩**：对历史进行抽象提取，支持长程依赖。
* **Token 预算管理**：主动控制记忆量以优化成本与性能。
* **长时记忆实现**：向量检索 + 语义相关性注入。

### 4. RAG 技术解析
* **检索增强原因**：避免文档全量注入导致的 Token 溢出与噪声干扰。
* **向量相似度**：如余弦相似度，用于衡量语义关联性。
* **嵌入模型（Embedding）**：将文本映射到高维向量空间。
* **完整链路**：文档切割 → 向量化 → 检索 → 结果注入上下文。

### 5. Tool / Skill 架构
* **Function Calling 机制**：两轮交互（模型提议 → 系统执行返回）。
* **工具描述（Schema）**：通过声明式定义引导模型选择工具。
* **Skill 封装**：可复用能力单元，高于工具层的抽象。
* **设计原则**：清晰的描述（Description）比实现细节更重要。

### 6. Agent 工作流循环
* **ReAct 模式**：推理（Reasoning）与行动（Action）的交替循环。
* **Thought 价值**：显式推理过程引导决策，非简单注释。
* **AgentExecutor 职责**：任务分发、工具调用与结果整合。
* **终止条件**：明确完成标准，防止无限循环。

### 7. 多 Agent 系统
* **协作需求**：突破单上下文限制、并行处理、专业化分工。
* **拓扑结构**：
    * **主从模式（Orchestrator-Worker）**
    * **流水线处理（Pipeline）**
    * **对等协作（Joint Collaboration）**
* **通信模式**：共享状态与消息传递的适用场景对比。

### 8. 架构分层模型
#### 五层功能视角
1. **模型层**：LLM 推理、Function Calling、输出解析。
2. **记忆层**：短时/长时记忆、RAG 检索。
3. **执行层**：工具调用、外部 API 集成。
4. **编排层**：任务规划、多 Agent 协调。
5. **交互层**：用户界面、多模态输入输出。

#### 七层工程视角（扩展生产需求）
* **安全与治理层**：权限控制、审计日志、Guardrails（防护栏）。
* **评估与反馈层**：质量监控、持续优化闭环。

## 第二部分：进阶篇

### 1. RAG 进阶优化
* **查询优化**：Multi-Query、HyDE 假设生成、查询改写。
* **索引优化**：父子块（Parent-Child Chunk）、语义分块、层级索引。
* **召回后处理**：交叉编码重排序（Rerank）、混合检索（稠密 + BM25）。
* **GraphRAG**：知识图谱增强跨文档关联。
* **评估体系**：RAGAS 框架（精度、召回、忠实度、相关性）。

### 2. Memory 长期化实践
* **记忆分层**：工作记忆、情节记忆、语义记忆。
* **Mem0 服务**：专为 Agent 设计的记忆管理方案。
* **跨会话实现**：存储选型（Redis/DB）、检索策略、异步更新。
* **压缩与遗忘**：重要性加权、主动遗忘机制。

### 3. 三大框架对比实战
* **LangGraph**：状态机驱动的工作流，支持人工介入与“时间旅行”。
* **CrewAI**：角色驱动的团队协作模式，内置规划与护栏。
* **Google ADK**：生产导向，深度集成 Vertex AI 生态。

## 第四部分：工程化篇

### 1. LLM Gateway 中台
* **核心功能**：Key 管理、成本控制、模型路由、限流。
* **方案**：LiteLLM (统一接口)、PortKey (降本增效)。

### 2. Harness 评测体系
* **三层评测**：组件级、任务级、系统级。
* **自动化**：Promptfoo + CI/CD 集成。

### 3. 可观测性建设
* **方案**：LangSmith (全链路追踪)、Langfuse (开源自托管)。
* **指标**：任务完成率、TTFT（首字延迟）、Token 消耗、错误率。

### 4. 安全防护体系
* **内容安全**：Prompt Injection 防护、宪法链（Constitutional AI）。
* **系统安全**：权限控制、工具权限最小化、人工审批机制。

### 5. 成本与性能优化
* **压缩**：LLMLingua 上下文摘要。
* **缓存**：语义缓存（Semantic Cache）复用。
* **自动优化**：使用 **DSPy** 程序化自动优化 Prompt。

### 6. 全栈 LLMOps 平台
* **后端基座**：FastAPI + PostgreSQL + JWT。
* **前端监控**：Vue3 + TailwindCSS + ECharts。
* **部署**：Docker + 云原生架构 + 生态集成（飞书/钉钉）。
